## Context

Extend the notes app with AI chat capabilities that leverage the existing sync system and CRDT infrastructure. Users should be able to have conversations with AI models (via OpenRouter for multi-provider support), where chat history is encrypted and stored using the same CRDT-based approach as notes. Chats should be bidirectionally linked with notes - users can reference notes within chats and backlink to chats from within notes.

## Goal

Implement an AI chat system that stores encrypted chat history using CRDTs, integrates with OpenRouter for multi-provider AI access, and enables bidirectional linking between chats and notes.
