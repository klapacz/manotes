## Context

Idea for a browser extension that communicates with the app. Users should be able to backlink to any open browser tab from within their notes. A note for the tab should be automatically created to avoid the need to manually copy links to notes.

## Goal

Enable users to create backlinks from notes to open browser tabs with automatic note creation for the referenced tabs.
